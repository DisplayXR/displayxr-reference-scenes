# DisplayXR material test scenes

Generated measurement scenes. Each one sweeps one material property in
controlled steps, so a renderer change shows up as a specific row rather than
as "the image looks different".

| File | Sweeps |
|---|---|
| `material_grid.glb` | 9 `KHR_materials_*` families × 7 steps: the model viewer's frozen regression baseline |
| `coat_test.glb` | `KHR_materials_coat` (draft): factor, colour, darkening, IOR, anisotropy, coat normal |
| `diffuse_fuzz_test.glb` | `KHR_materials_diffuse_roughness` + `KHR_materials_fuzz` (drafts) |
| `transmission_test.glb` | transmission over a structured backdrop, a step-vs-ramp acceptance test |

Generated by `displayxr-demo-modelviewer` at the commit pinned in
[scene.json](scene.json), and dedicated to the public domain
([CC0-1.0](../../LICENSES/CC0-1.0.txt)).
